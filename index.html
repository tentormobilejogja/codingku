Status koneksiBelum terhubung · Mode demo/CSV

Prototype ini belum mengirim token ke server. Jangan tempelkan token di halaman ini. Integrasi live membutuhkan backend privat, login, enkripsi token di server, dan konfigurasi Meta App.

Persiapan akun

  1. Pastikan akun Instagram adalah Professional (Business atau Creator).
  2. Hubungkan akun Instagram Professional ke Facebook Page yang dikelola.
  3. Buat Meta App dan konfigurasi produk/login yang sesuai untuk Instagram API with Facebook Login.
  4. Gunakan Graph API Explorer untuk membuat User Access Token dan pilih Page serta izin yang diperlukan.
  5. Verifikasi izin terbaru di dokumentasi resmi Meta sebelum implementasi.

Izin yang perlu diverifikasi: pages_show_list, pages_read_engagement, instagram_basic, instagram_manage_insights.

Uji koneksi live yang kelak perlu dilakukan: validasi token, daftar Page, akun Instagram Professional yang terhubung, lalu ambil insights. Error harus dipisahkan menjadi token kedaluwarsa, izin kurang, Page/IG tidak ditemukan, dan API gagal dihubungi.

Development/Standard Access: umumnya cocok untuk pengembangan dan akun/role yang terdaftar pada app; penggunaan oleh akun eksternal dapat memerlukan App Review serta Advanced Access sesuai izin dan ketentuan Meta.
